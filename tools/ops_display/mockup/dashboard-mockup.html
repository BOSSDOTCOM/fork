About this mockup

Figures are a real snapshot read from the job files, logs and reports on Sat Nov 14 at 12:35 PM EST. Figures with a dotted underline are simulated, because nothing records them yet (CPU load, shard progress inside a GitHub run, sparkline history).

Lane B really ran a second screen at that moment. It replays this morning's capture-evaluation test at its fifth stage instead, so the display of a running SPRT can be judged.

The dashboard only displays. It has no control that starts, stops or changes anything; "seen" on an alert only dims it on this screen.
