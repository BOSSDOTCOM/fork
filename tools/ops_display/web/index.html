What this screen is

A display. It reads the job files, logs and reports and shows them; it has no control that starts, stops or changes anything, and it writes no file.

"Seen" on an alert dims it in this window only, until the page is reloaded.

Times are EST. Hover a name for its internal name (queue item, test, job, file).
