# Fork: Originality Record

This file supports Fork's TCEC application. It lists every reference
consulted, every third-party library used, and the provenance of all
training data. All Fork source code is original. No source code, network
file, or engine-generated training data from any other engine is included.

Entries are added when the reference or library is first used, with
the date and the part of Fork it informed.

## Rules Fork follows

- References are read for *techniques*. Code is written from Fork's own
  design (docs/DESIGN.md), not translated from another engine's source.
- Lookup constants (magic numbers, Zobrist keys) are generated by Fork's own
  code from fixed seeds. They are never copied from published tables.
- Expected perft counts are published facts and are used as test oracles
  only.
- NNUE networks are trained only on data Fork generated itself (Phase 4).
  Their provenance is logged below.
